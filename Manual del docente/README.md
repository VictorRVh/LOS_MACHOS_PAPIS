# CETPRO Puno Manual para el Docente

Contenido de la carpeta:

- `cetpro-puno-manual-para-el-docente.tex`: manual completo en LaTeX.
- `compilar_manual.bat`: comando base para compilar en Windows con `pdflatex`.

Activos usados por el manual:

- `../public/img/cetprologoHorizontal.png`
- `../public/img/CETPRO_Image.png`

Compilaci\'on sugerida:

```bat
cd "Manual del docente"
compilar_manual.bat
```

Si no tienes LaTeX instalado, puedes abrir el archivo `.tex` en Overleaf o instalar TeX Live / MiKTeX.
